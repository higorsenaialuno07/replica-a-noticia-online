# Portal A Notícia

Reconstrução do layout do portal de notícias **A Notícia Online** (Muriaé-MG) usando apenas HTML5 e CSS3, sem frameworks.

O projeto cobre a página inicial (destaques, últimas notícias, previsão do tempo e widgets laterais), as editorias (Cotidiano, Polícia, Cultura, Região, Esporte, Eventos e Opinião) e as páginas institucionais (História, Expediente e Fale Conosco).

## Como abrir
Basta clonar o repositório e abrir o arquivo `index.html` diretamente no navegador.
